## 语义锚点

| 模块 | 语义推断 | 关键锚点 |
|---|---|---|
| MOD-01 | 引导/IRQ/系统服务 | `VBlankIntr`(080065C), 事件标志位图 0801030/08010AC/08010EC, 主回调表 |
| MOD-02 | 精灵动画/图形资源 + 存档底层 | `UpdateSpriteAnim`(0807A1C), `LoadSpriteAnimSet`(0808BA4), save.c SRAM 驱动 |
| MOD-03 | 存档菜单/文本/背包/SIO/图块 (F3b+F4a-f) | 存档流程块(08011454/08012790/08013F3C), 080166A4 字符绘制, `gInventory`, SIO 泵(08016E30/08016F30) |
